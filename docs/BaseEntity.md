Why BaseEntity?
⇒ Almost every table will have createdAt and updatedAt.
Instead of creating them in every entity I'll put them in one place and required entity will extend this class.

Why @MappedSuperclass ?
⇒ @MappedSuperclass is used when a class contains common fields that should be inherited by multiple entities.
JPA does not create a table for the superclass; instead, its fields are mapped into the child entity tables.

Why abstract?
⇒ I don't want to create an object of this class.
Its fields are mapped into the child entity who extends this class(BaseEntity).

Example:
⇒ Our member entity will use createdAt and updatedAt fields that's why I don't need to write it in member entity.
Generated member table will contain createdAt and updatedAt columns.

@PrePersist?
⇒The @PrePersist method is executed before a new entity is persisted to the database. 
@PreUpdate?
⇒The @PreUpdate method is executed before an existing entity is updated in the database.
In short: @PrePersist handles values before INSERT, while @PreUpdate handles values before UPDATE.

@Column?
⇒ The JPA @Column annotation is used to define how an entity field maps to a database column.
nullable = false — The database column cannot contain NULL values. This indicates that the field is mandatory.
updatable = false — The column will not be included in SQL UPDATE statements generated by JPA after the entity has been
persisted( saved/stored).

@Getter & @Setter ?
⇒ I used lombok annotations to generate repetitive code.
These annotations write getter & setter method automatically.
